# Changelog

Release notes for each version are on [GitHub Releases](https://github.com/earthly/lunar-lib/releases).
The full changelog is `CHANGELOG.md` at each release tag, for example
[v1.22.0](https://github.com/earthly/lunar-lib/blob/v1.22.0/CHANGELOG.md).

`scripts/release.sh` writes each version's section onto the tag from the merged
PR titles. This copy on `main` stays a pointer, so PRs don't edit it.
